# relife-ocdl

Download osu!Collector collections, tournaments and user uploads straight into your osu! Songs folder.

Fork of [roogue/osu-collector-dl](https://github.com/roogue/osu-collector-dl), heavily reworked.

## Download

### ⬇️ [Download for Windows (.zip)](https://github.com/Nyhvatit/relife-osu-collector-dl/releases/download/v14.8.8/relife-ocdl-v14.8.8-win-x64.zip)

1. Click the link above to download the `.zip`.
2. Unzip it anywhere (right-click → Extract All).
3. Double-click **`relife-ocdl.exe`** and follow the instructions on screen.

No installation needed. Newest version is always on the [Releases page](https://github.com/Nyhvatit/relife-osu-collector-dl/releases/latest).

## Features

Collection downloads, Tournament downloads, User uploads, Multiple mirrors, Mirror rotation, Parallel downloads, Rate-limit aware, Skip existing, collection.db export, .osdb export, No-video mode, Retry failed, Update collections, Auto backups, Setup wizard, Diagnostics log.
